# Weather Dashboard App

A simple and interactive weather dashboard web app that displays current weather information for any city, along with weather data for common cities in a table. Features temperature conversion, sunrise/sunset time, wind speed, humidity, and more.

---

## Features

- Search weather by city name.
- Displays current temperature, feels like, min/max temperatures in Celsius.
- Shows wind speed, wind direction, humidity, and atmospheric pressure.
- Sunrise and sunset times with local time formatting.
- Weather condition description.
- Table showing weather for common cities with live data.
- Temperature conversion from Kelvin to Celsius.
- Responsive and clean UI using Bootstrap.
- Error handling for invalid city names.

## Installation & Setup

1. Clone or download the repository.

2. Open the `index.html` file in any modern web browser.

3. Make sure you have a valid API key for the weather API service (e.g., RapidAPI).

4. Replace the `apiKey` and `apiHost` values in `script.js` with your own credentials.

---

## Usage

- Enter a city name in the search box and click the "Submit" button.
- View detailed weather data for the searched city.
- See the weather data for common cities updated automatically in the table.
